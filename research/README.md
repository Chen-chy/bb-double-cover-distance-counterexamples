# Complete research sources and executable evidence

[GitHub reading edition](../results/README.md) · [All result records](../results/CLAIMS.md)

The amplification and degradation directories contain the complete retained research rounds, their original proof files, data, exact optimization certificates, discovery scripts and independent audits. They are primary research contents, not optional manuscript supplements. The byte-preserving relocation from the earlier `archive/` layout is recorded in `provenance/github_reorganization.json`.

Run [amplification](amplification/README.md) or [degradation](degradation/README.md) separately, or use the root extended profile. Original historical navigation/status pages are retained for provenance; the root `results/` edition repairs current navigation and status rather than silently modifying historical files.

The [beyond-trinomials report](beyond-trinomials/README.md) is a complete public mathematical transcription, with a separate evidence status. See each topic's original README for expensive discovery and classification commands beyond the retained-audit profile.

The [homology and class-metric branch](homology/README.md) restores five complete mathematical reports from the third input ZIP. The original early audit programs remain in `archive/early_counterexample/` and have a dedicated root verification driver.
