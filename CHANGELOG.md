# Changelog

## 0.2.1 — Principal report and evidence triage

Added root REPORT.md and REPORT.en.md as the first README links. The 104 entries are explicitly research records, not 104 established theorems. A reviewed adoption policy separates headline/scoped results, valid negative results, historical bounds, evidence gaps, searches, open questions and out-of-scope constructions. Each complete reading note has a specific current-use warning, without altering original source bytes.

The weight-six input dependency and related combined consequences are now explicitly gated; no missing input was silently proved by editing a summary. Fixed-message 74N, restricted minimum 16 and five-term lifts are excluded from full-distance headline claims. Open entries link to problem statements, not purported proofs. The CLI defaults to principal records and supports explicit views. Current status overrides the obsolete finite missing-certificate note while preserving that old wording as history.

No theorem constant changes. Added consistency checks and regression tests for adoption boundaries; prior audit logs remain labeled as prior logs.

## 0.2.0 — Standalone GitHub research edition

The repository is now the complete research product, rather than a manuscript-plus-ancillary export. The main research branches are promoted from `archive/` to `research/` without changing original bytes. Seven complete theory chapters and twenty-five complete note reading editions are available under `results/`. The original 38+40 claim records are restored and merged with 16 main entries into a 104-entry register with explicit status overlays.

The previously omitted public arbitrary-term mathematical report is restored, with its outside-trinomial scope and missing-original-verifier status preserved. Raw task/conversation dumps and third-party PDFs remain excluded.

Added CLI result lookup and counterexample comparison, package installation tests, a source/links/catalog validator, GitHub CI and manual research audit workflows, complete-source release packaging, GitHub publishing instructions/tooling, citation guidance, and an offline-cloneable Git bundle. Manuscript approval metadata is not a gate on repository technical checks. No mathematical theorem is silently upgraded by the restructuring.

Merged the two finite counterexample certificates with the amplification and degradation research branches; added the common convenience library, cross-comparison runner, consolidated symbolic proofs and optional arXiv source packaging.
