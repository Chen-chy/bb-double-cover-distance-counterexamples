The complete mathematical exposition is [results/theory/01-counterexamples.md](../results/theory/01-counterexamples.md); the exhaustion proof is [results/theory/06-certificate-algorithms.md](../results/theory/06-certificate-algorithms.md). Run `python scripts/reproduce.py --profile core --output checks/local` from the repository root for all four programs and cross-comparisons.

Historical `ORIGINAL_SHA256SUMS.txt` files describe original layouts and may name the intentionally excluded third-party PDF. The current source integrity authority is the root manifest and `provenance/import_map.json`.
