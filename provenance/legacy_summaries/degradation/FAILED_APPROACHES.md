# Counterexamples, failed shortcuts, and hypotheses that matter

Each entry is a preserved research outcome. A failed proof idea is not automatically a counterexample to the main distance conjecture. Sources below retain the proofs and exact data.

## Metric and homological shortcuts

**Transfer injectivity protects Hamming norms.** The early four-term family and the inherited degradation seed invalidate this general inference. The four-term example has exact transfer compression and an exact filling distortion formula, but it is outside the strict-trinomial class. Its early original code package is unavailable; its public derivation is retained in the [early report](../context/conversation/00-arbitrary-term-public-report.md).

**A long chosen base class controls code distance.** The early two-parameter four-term family has a distinguished class of length $2a+1$ while another logical has weight $b$. Fixing $b$ defeats the claimed distance growth. Later retained-involution and high-contact families likewise contain independent short base logicals. No selected-sector bound replaces the full code minimum.

**Unbounded filling distortion alone gives degradation.** The [weight-six note, Sections 5–6](../research/01-weight-six/proof.md) constructs weight-six base boundaries with exact coefficient minimum $3\cdot9^j$ and lifted filling order $9^j$, but every cycle above those particular boundaries is also long. It disproves the two-check filling lemma and bounded filling norms, not the strict-trinomial constant-ratio question.

## Finite/local specialization pitfalls

**Formal cycles are finite nonboundaries.** Every classification package separates formal incidence cycles from their actual finite homology. Explicit fillings, unit components, projector sectors, and independent short logicals are retained as separate resolutions.

**A local normal form is a sparse physical normal form.** The [visible-two-primary note](../research/05-visible-two-primary/proof.md) restricts actual local modules to two branches over one nilpotent parameter, but its coordinate changes need not preserve weight. Its high-contact family has base distance four despite arbitrarily deep local lengths.

**Semisimple compact homology always survives torsion-changing projection.** The [quadratic-bottleneck note](../research/04-quadratic-bottleneck/proof.md) gives a strict-trinomial torsion-changing example with simple universal compact $H_1$ whose compact image is killed. The quotient is by a zerodivisor; a principal nonzerodivisor-period exact sequence cannot be applied to it. The base has an independent weight-two logical, so it is not a degradation counterfamily.

**Specialization commutes with homology without a correction.** The same note preserves the exact compact injection and the separate $H_0[f]$ term. Later rank-one amplification notes retain that distinction until their explicit period-stabilization argument controls short finite cycles.

**An order-three projector is nontrivial whenever the whole code encodes.** Its own character summand may be acyclic. The structural odd-sector checks retain the earlier filling example as a negative control. Do not drop the active-summand condition from nilpotent witness lemmas.

## Incidence and geometric shortcuts

**Short relation rows force quadratic cofactors.** The rank-one lattice with rows $(L,-1,0,0)$, $(0,L,-1,0)$, $(0,0,L,-1)$ has cofactor $(1,L,L^2,L^3)$ despite being saturated. This is a counterexample to a purely arithmetic estimate, not a distance counterexample. See [stage 04](../research/04-quadratic-bottleneck/proof.md).

**No elementary shortening means nonboundary.** The [weight-eight note](../research/02-weight-eight/proof.md) keeps universal boundaries needing multiple checks, including the arithmetic-progression example from $(1+x)(1+y)$. A local overlap test only discards certain candidates; passing it does not certify homology.

## Physical replacement and amplification pitfalls

**Kill the incidence involution even when the actual base retains it.** The [sparse-deck note](../research/06-sparse-deck-descent/proof.md) gives an exact retained-involution period family for which the derivative output has nonzero syndrome in the real base. The deck-killed subclass theorem cannot be applied to the wrong quotient. The same attempted family has short independent base logicals and is not a distance counterfamily.

**The naive Frobenius $3w$ cycle always works.** The [rank-one note](../research/07-rank-one-amplification/proof.md) shows its class is a multiplier of the transferred base class. When transfer is killed, this candidate is a boundary as well, sometimes with an explicit universal filling. This refutes the candidate nonboundary argument, not factor three.

**Constant messages minimize the relative Laurent norm.** The [mixed-Laurent note](../research/08-mixed-laurent/proof.md) supplies an exact parametric four-term input with linearly better cancellation than the constant message. Its constructed cover word is only an upper bound; no full-minimum ratio can be deduced from two upper-bound representatives.

**The systematic identity alone yields a linear bound.** The [fixed-$c$ note, Section 7](../research/09-fixed-c-product-bound/proof.md) has exact full minima $\mu_0=2$, $\mu_+=4N+2$ under the same algebraic identity, but the lifted numerator has five supported terms and invalid termwise projection. The example rules out an overbroad proof, not the actual strict-trinomial claim.

**Refuting the half-generator lemma refutes factor three.** No: that would only place an instance in the necessary stronger-cancellation regime. A target counterexample still needs a certified lower bound on the unrestricted cover minimum over all $F,H$.

## What is not claimed

Neither strict-trinomial degradation to zero nor unbounded strict-trinomial amplification is proved in these retained stages. No unresolved main inequality has been silently upgraded by including an illustrative finite check or a counterexample outside its hypotheses.
