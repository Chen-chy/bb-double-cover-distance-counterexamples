# 结果与证明入口

独立 GitHub 正文以 [results/README.md](../results/README.md) 为入口，全部逐项证据见 [results/CLAIMS.md](../results/CLAIMS.md)。

主理论有七章完整论证，两个研究支线及范围外公开报告有二十五篇完整阅读版。原始 `.md`、程序、数据在 `research/`。`paper/` 只是可选排版稿，不再是全部研究内容的唯一权威入口。

查询指定结果：`python -m bbcover results DIST-UPPER`。结论字段与证据类型说明见 [DATA_FORMATS.md](DATA_FORMATS.md)。
